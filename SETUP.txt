IMPORTANT DATABASE STEP
Run the updated schema.sql in Supabase SQL Editor before uploading the new app files.
It adds:
- game player order
- custom/highest/lowest sorting mode
- player history indexes
- avatar support and storage setup

FEATURES IN THIS VERSION
- Classic, simpler visual design
- Dark and light mode
- Games tab with 🎮 game icons
- Larger, bolder bottom navigation
- Create, rename, finish, reopen, and delete games
- Add, edit, and delete players
- Player pictures
- Any score amount, positive or negative
- Quick score buttons
- Custom player order with up/down controls
- Highest score first
- Lowest score first
- Game-wide history
- Tap a game in History to see every score change
- Tap a score change/player to see that player's history for that game
- Delete all history for a game
- Undo the most recent score change
- Round tracking
- Cloud sync

The current RLS policies are open to anyone who has the app's public key.
For a private app, add Supabase Authentication and user-specific RLS before making the app public.
